PMax Settings PF_Algo V69

PMax = Profit Maximizer. C'est le coeur de la strategie : une Moyenne Mobile (MA) combinee avec l'ATR (Average True Range) pour creer la Red Line (ligne de stop dynamique).
Red Line = MA ± (ATR × Multiplier). Elle sert de trailing stop et definit la tendance : prix au-dessus = haussier, en-dessous = baissier.
Type de calcul de la moyenne mobile PMax
Nombre de periodes pour le calcul de la MA (defaut: 10)
Plus haut = Red Line plus eloignee du prix (defaut: 3.0)

Signal d'Entree Inp Entry Type

Le type de signal qui declenche les entrees Long/Short. Chaque signal a ses propres parametres specifiques.
Order Pause = nombre minimum de barres a attendre entre deux trades (evite l'over-trading).
Nb barres minimum entre 2 trades (defaut: 5)

Parametres Donc+Chikou

Canal Donchian : High/Low sur N periodes (defaut: 20)

Parametres RSI Divergence

Parametres Fractal

Parametres Bollinger + SMA

Parametres MM Cross (signal d'entree)

Croisement de 2 Moyennes Mobiles comme signal d'entree : Long quand la rapide croise au-dessus de la lente, Short quand en-dessous.

Filtres de Tendance & Confirmation

Filtre Tendance Long Terme (LT) Inp LT Trend filter

Bloque les trades contre la tendance de fond (higher timeframe).
Le filtre calcule un PMax sur le timeframe superieur (ex: Weekly) :
• Long autorise si le prix est au-dessus de la Red Line HTF (= MA + ATR × Mult sur le TF superieur)
• Short autorise si le prix est en-dessous de la Red Line HTF
Vous definissez le Timeframe, le Type de MA, la Longueur et le Multiplicateur ATR utilises pour ce PMax HTF.
Timeframe du PMax LT (defaut: Weekly)
Type de moyenne mobile (defaut: EMA)
Nb periodes MA sur le TF LT (defaut: 20)
Largeur de la Red Line LT = ATR × ce multiplicateur (defaut: 1.5)

Filtre Tendance Moyen Terme (MT) Inp MT Trend filter

Meme logique que le filtre LT, mais sur un timeframe intermediaire (ex: 4H).
Permet de filtrer les entrees en combinant une vision long terme + moyen terme de la tendance.
• Long autorise si le prix est au-dessus de la Red Line MT
• Short autorise si le prix est en-dessous de la Red Line MT
Timeframe du PMax MT (defaut: 4H)
Type de moyenne mobile (defaut: EMA)
Nb periodes MA sur le TF MT (defaut: 10)
Largeur de la Red Line MT (defaut: 1.5)

RSI > 50 Filter Inp RSI 50 Filter

Long autorise uniquement si RSI(14) > 50.
Short autorise uniquement si RSI(14) < 50.

MA Direction Filter Inp MA Dir Filter

Bloque le trade si la MA ne monte pas (Long) ou ne descend pas (Short) sur les N dernieres barres.

MAvg Position Filter Inp MAvg Filter

Long autorise si le prix est au-dessus de la MA PMax.
Short autorise si le prix est en-dessous de la MA PMax.

Diff MA / Red Line (ecart max en %) Inp diff_ma_filter

Bloque l'entree si l'ecart entre la Moyenne Mobile PMax et la Red Line depasse le % defini.
Quand la MA est tres eloignee de la Red Line, le stop dynamique est large et le risk/reward defavorable.
Exemple : Max Diff = 1% → si |MA - RedLine| / prix > 1%, le trade est bloque.
Plus le % est bas, plus le filtre est strict.
% maximum d'ecart autorise (defaut: 1.0%)

Diff Price / Red Line (ecart max en %) Inp diff_price_filter

Bloque l'entree si l'ecart entre le Prix actuel et la Red Line depasse le % defini.
Quand le prix est tres loin de la Red Line (zone PMax), entrer expose a un retour rapide vers le stop.
Exemple : Max Diff = 1% → si |Prix - RedLine| / prix > 1%, le trade est bloque.
Plus le % est bas, plus le filtre est strict.
% maximum d'ecart autorise (defaut: 1.0%)

Risk Management Inp SL Mode

Comment le Stop Loss est gere et quels cotes (Long/Short) sont autorises.
4 modes de SL disponibles :
• Static - % : SL fixe a X% du prix d'entree (ex: 30% = SL large, 5% = SL serre)
• Red Line : SL place directement sur la Red Line PMax (stop dynamique qui suit le prix)
• ATR-Based : SL = prix ± (ATR × Multiple). Vous definissez le multiple de l'ATR ci-dessous. Plus le multiple est haut, plus le SL est large. Recommande: 1.5 - 3.0
• No SL : pas de stop loss (sortie uniquement par signal inverse)
% de perte max par trade (defaut: 30%)
SL = prix ± (ATR(14) × ce multiple). Recommande: 1.5 - 3.0 (defaut: 2.0)
